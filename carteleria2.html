Generador de cartelería de depósito — RPM Construcciones

Usá esta herramienta para imprimir la señalización de ubicación de cualquier estantería del depósito. Elegí el tipo de cartel que necesitás: Celdas (identifica cada casillero, ej. 1B), Filas (letra grande para ubicar el nivel desde el pasillo), Estantes (identifica cada mueble/estantería completo), Rótulos (nombre de producto o carpeta) o Referencias (título + lista de familias). Configurá cantidad, tamaño y color según el estante que estés señalizando, generá los carteles e imprimilos — cada uno sale con una línea punteada para guiar el corte.

Consejos para armar y colocar la cartelería
  1. Un color por depósito. Si hay más de un depósito, usá un color distinto en el selector para cada uno — así se identifica de un vistazo en cuál estás parado.
  2. Protegé el papel. Si se imprime en papel común, una funda autoadhesiva transparente o cinta de embalar por encima ayuda a que dure más contra el polvo y el manoseo.
  3. Tamaño según distancia de lectura: el cartel de Estante se lee cruzando el depósito, el de Fila desde el pasillo, y el de Celda de cerca, parado frente al estante. Ajustá el tamaño de cada uno pensando desde dónde se va a leer.
  4. Rótulos de nombre: usá el mismo ancho/alto/color para todos los rótulos de un mismo depósito — así, aunque los nombres tengan largos distintos, todos los carteles quedan con el mismo formato. La app recuerda automáticamente los últimos valores que usaste.
